# Growth Reports

Monthly growth reports for InvoiceChain (Level 7 — Founder Belt requirement).

## Cadence
One report per calendar month, named `YYYY-MM.md`. Publish within the first few
days of the following month.

## How to produce a report
1. Refresh on-chain numbers:
   ```bash
   ./scripts/growth_metrics.sh
   ```
2. Copy the previous month's file to `docs/growth/YYYY-MM.md`.
3. Fill the metric table (move this month's numbers into "Last month"), the
   product-updates section (with commit/PR links), feedback highlights, and
   social/community activity.
4. Update the index below and commit.
